## 结论先行

| 结构 | 必要性 | 充分性 | 反例 | 分类 |
|---|---|---|---|---|
| ① `divisorResidueSet` | **精确双射**（每个解都给出，每个成员都给出解） | **等价** | 单边判据需 `gcd(M,a)=1`，有反例 | **B/C**（重构，等价难度）；其单边判据是**A（次要新定理）** |

| ③ 有界指数乘积集 | **平凡真**（唯一分解） | **等价**；「子群」版本**更强但假** | `R(2,5)={1,2,4}≠⟨2⟩={1,2,3,4}` | **B**（正确重构，非新结构）；其「子群」版为 **D** |

## 结构 ①：`divisorResidueSet R(M,a)`

### 1. 必要性测试 — **精确成立，且是双射**

每个解 `(x,y,z)` 都经由 `solution_gives_certificate`（`Certificate.lean`，**[A]**）给出
`(a,d,e)`，其中 `d·e = (n·x)²`、`a ∣ d+n·x`、`a ∣ e+n·x`。令 `M = n·x`，则 `d ∣ M²` 且
`d ≡ −M (mod a)`，即 **`−M mod a ∈ R(M,a)`**。

反之，`d ≡ −M (mod a)` 的因子 `d`（在 `gcd(M,a)=1` 时）经由 `certificate_iff_one_sided`
（`NewStructures.lean`，**[A]**）自动补出 `e = M²/d` 满足第二条同余，再经
`solvable_iff_certificate` 反演出解。

**结论**：结构**自然且精确地**从每个解产生，是**双射**，不是「恰好出现」。

### 2. 充分性测试 — **等价**（非更强、非更弱）

「`∃ x, a = 4x−n > 0, −M mod a ∈ R(M,a)`」与「`n` 可解」**等价**（上述双射的换一种说法）。
它不是*更强*（不蕴含猜想之外的结论），也不是*更弱*（不丢弃信息）。**等价难度。**

### 3. 反例搜索 — **找到单边判据的「缺失假设」**

单边判据 `certificate_iff_one_sided` 要求 `gcd(M,a)=1`。压力测试证明该假设**不可省**：

- 最小反例 `M=2, a=6`（`gcd=2`）：`d=4` 满足 `6 ∣ 4+2 = 6`（单边成立），但补因子
  `e = M²/d = 1` 有 `6 ∤ 1+2 = 3`（双边失败）。**（M,a）< 40 内共 10 个反例**。
- 佐证：`gcd(M,a)=1` 时，`M,a < 60` 全部 0 失配（与 Lean 定理一致）。

**关键修正（必要性测试的精确推论）**：在 Erdős–Straus 的实际设置里 `gcd(M,q)=1` **自动成立**
——对素数 `n = p ≡ 1 (mod 4)`、素数层 `a = q ≡ 3 (mod 4)`：

> **Lemma（初等，register A，未入 Lean）。** `q ∣ M = p(p+q)/4 ⟹ q ∣ p(p+q) ⟹ q ∣ p ∨ q ∣ p+q
> ⟹ q ∣ p`（`q` 奇素数、`q ∤ 4`）。但 `p` 素数且 `p ≠ q`（不同 mod 4），故 `q ∤ p`，矛盾。
> 故 `gcd(M,q)=1`。

因此**对素 `a` 层（最小 `a` 的主宰情形）单边判据无条件适用**；`gcd` 假设只在复合 `a` 层才真正
是约束（那里 `gcd(M,a)>1` 确实可能，见反例）。

### 4. 化简 — 化为已知对象

`gcd(M,a)=1` 时 `R(M,a) ⊆ (ℤ/a)^×`，且是**指数盒** `[0,2v₁]×⋯×[0,2vᵣ]` 在映射
`(f₁,…,fᵣ) ↦ ∏ g_i^{f_i}`（`g_i = p_i mod a`）下的像。于是：

- 证书条件 = **有限阿贝尔群里的「有界表示 / 子集和」问题**（`−M` 是否落在指数盒的像里）。
- 也就是经典的 **「除子在给定剩余类」问题**（divisor in a residue class；Fouvry 等）。
- 整个猜想 = 对每个素数 `p`，目标 `−M` 被某个 `a ≡ 3 (mod 4)` 的 `R(M,a)` **覆盖**（covering）。

**这是问题类型的正确识别，但不降低难度。**

### 5. 文献对比

「`n²` 的除子在剩余类中」是**标准除子参数化**（Mordell / Elsholtz–Tao 的 `f(n)` 除子计数 /
Swett / Salez 的每一条模恒等式都对应一个特定剩余类里的除子）。`R(M,a)` 作为*命名对象*不标准，
但其**内容**是古典的。单边坍缩（`gcd=1` 时一条同余推出另一条）是**单位元的初等模算术**，
folklore 级别，未在我们读到的文献中以定理形式出现。

**分类：B/C**（等价难度的重构）；其单边判据是**次要的 A**（新验证定理，统一 `a=3/7/…`，但
不触六类核心）。

## 结构 ②：`AstratumSolvable n a`

### 1. 必要性 — **精确**

`solvable_iff_exists_stratum`（`NewStructures.lean`，**[A]**）：`Solvable n ↔ ∃ a>0,
AstratumSolvable n a`。每个解都落在某个 `a = 4x − n` 层，且每个非空层都给出解。精确。

### 2. 充分性 — **等价**

同上定理，**等价**。它把可解性组织成「按参数 `a` 分层」，不减少难度（「存在某个非空层」正是
猜想本身）。

### 3. 反例搜索 — **无不变量本身的反例；`minimal a` 增长是 C 不是反例**

计算（`p ≡ 1 (mod 4)`，`p ≤ 10⁵`）给出**最小 `a` 的新纪录序列**（按 `p` 递增的首次突破）：

```
p =      5  ->  minimal a =  3
p =     73  ->  minimal a =  7
p =   1129  ->  minimal a = 11
p =   1201  ->  minimal a = 23
p =  21169  ->  minimal a = 31
```

**每个 minimal-a 值的首次出现**（`p ≤ 30000`，精确）：

| minimal `a` | 3 | 7 | 11 | 15 | 19 | 23 | 31 |
|---|---|---|---|---|---|---|---|
| 首次 `p` | 5 | 73 | 1129 | 2689 | 7561 | 1201 | 21169 |

故「按 `p` 递增的纪录」（严格增长序列）是 `3,7,11,23,31`——`23` 在 `p=1201` 就已达，跳到
`15`（`p=2689`）、`19`（`p=7561`）之前；而「值集」是**无间隙的完全初始段**
`{3,7,11,15,19,23,31}`（与 Phase 8b 一致，`p ≤ 2·10⁶` 到 `59`）。
每个 `p ≤ 10⁵` 都有某个 `a ≤ 119` 层可解（无猜想反例，早已知到远更大范围）。

**含义**：`minimal a` 是**真正有信息量**的不变量（区分素数、记录增长），支持「`a`-层是有用的
记帐重构」，但它**等价难度**，且「`minimal a` 无界」只是 **C**（数据支撑，不可由数据证明）。

### 4. 化简

`a`-层分解把猜想化为「覆盖问题」：`∀ p ≡ 1 (mod 4), ∃ a ≡ 3 (mod 4), a`-层非空。这与 Mordell
的六类约化（模 840 恒等式覆盖）是**同一覆盖框架**的显式化，只是把覆盖族从「模恒等式」换成
「`a`-层」。

### 5. 文献对比

按证书参数 `a = 4x − n` 分层**隐含**在所有除子参数化里（Elsholtz–Tao 的 `f(n)` 按除子计数正是
按 `(a,d)` 计数），但「最小证书 `a` 作为不变量」的显式记录是**本项目自产**（folklore 边缘）。

**分类：B/C**（等价难度的重构；`minimal a` 是有用的数据组织者，无难度降低）。

## 结构 ③：有界指数乘积集 `R(M,a) = { ∏ p_i^{f_i} : 0 ≤ f_i ≤ 2 v_i(M) }`

### 1. 必要性 — **平凡真（唯一分解）**

`M² = ∏ p_i^{2v_i(M)}` 的因子**恰是** `∏ p_i^{f_i}`（`0 ≤ f_i ≤ 2v_i`）。这不是「从解产生」，
而是**定义层面的恒真**（唯一分解定理）。所以它是 `R(M,a)` 的**正确描述**，不是新结构。

### 2. 充分性 — **等价；但「子群」版本更强且假**

- 「乘积集命中 `−M`」⟺ 证书 ⟺ 可解（**等价**）。
- Phase 8b 曾考虑的**更强**说法「`R(M,a)` = 素因子生成的子群 `⟨p_i⟩ ⊆ (ℤ/a)^×`」**是假的**，
  见下。

### 3. 反例搜索 — **子群说法被反驳**

| M | a | `R(M,a)`（有界指数） | 子群 `⟨p_i⟩` | 是否相等 |
|---|---|---|---|---|
| 2 | 5 | {1,2,4} | {1,2,3,4} | **否**（`3 ∈ ⟨2⟩ ∖ R`） |
| 3 | 7 | {1,2,3} | {1,2,3,4,5,6} | **否** |
| 5 | 7 | {1,4,5} | {1,2,3,4,5,6} | **否** |
| 6 | 11 | {1,2,3,4,6,7,9} | {1,…,10} | **否** |
| 2 | 7 | {1,2,4} | {1,2,4}（`ord₇(2)=3`） | 是（偶然） |

**结论**：指数上界（`f_i ≤ 2v_i`，来自「`M²` 的因子」而非「`M^k` 任意幂」）使 `R(M,a)` 一般是
子群的**真子集**。**难度恰在这里**：若指数无界，`R(M,a)` 就是子群，成员测试是纯群论（容易）；
有界指数把它变成**组合约束**（盒约束），这才是问题不平凡之处。

### 4. 化简

见结构 ① §4：盒约束 ⟺ 有限阿贝尔群的**有界表示 / 子集和**问题 ⟺ 「除子在剩余类」。这是把
`R(M,a)` 化到**已知问题族**的正确化简，但仍是**等价难度**。

### 5. 文献对比

「`n²` 的因子 = 有界指数乘积」是**唯一分解的换说法**，隐含于一切除子参数化文献；「子群」的
错误直觉在文献里不存在（我们读到的文献都直接对因子做指数有界处理）。**无新概念。**

**分类：B**（正确重构，非新结构）；其「子群」变体 **D**（假，已反驳）。

## 最终判定（A / B / C / D）

| 结构 | 分类 | 理由 |
|---|---|---|
| ① `divisorResidueSet` | **B/C** | 等价难度重构；但承载的**单边判据**是**次要 A**（新验证定理：两条同余压成一条，`gcd=1` 在素 `a` 层自动成立） |
| ② `AstratumSolvable` | **B/C** | 等价难度重构；`minimal a` 是有信息量的记帐不变量（记录 3,7,11,23,31,…） |
| ③ 有界指数乘积集 | **B** | 正确的重构（唯一分解），有诊断价值（驳斥子群、定位盒约束）；其「子群」版 **D** |

**总的杠杆结论**：这三个结构**都不减少猜想难度**（都是等价重构，或诊断性的正确描述）。唯一
可验证的新内容是**单边判据**（次要 A）——它统一了「容易层」并揭示了 `gcd` 假设在素 `a` 层
自动成立，但**不触及** `n ≡ 1,121,169,289,361,529 (mod 840)` 的六类核心。**猜想仍未解决，且
不声称已解决。**
