# Phase 9, Step 2–6 — 数学工具锦标赛

> **Legend:** **A** = proven · **B** = computational · **C** = conjecture · **D** = AI hypothesis.
> **Tool class (per the phase's mandatory 5-way):** (1) 新定义 · (2) 新猜想结构 · (3) 已证定理 ·
> (4) 有用的重构 · (5) 思辨性想法。**Never call speculation a discovery.**
> **Honesty rule (unchanged):** nothing here claims the Erdős–Straus conjecture is solved.

本阶段在五种观点（数论 / 代数 / 几何 / 概率 / 计算）下**发明**了 13 个候选数学对象，对每个
做了 **Grothendieck 检验**（「换个名字」vs.「真正增加结构」），并按 5 轴打分排名。
可验证的那一部分已形式化于 `Theorems/NewStructures.lean`（零 `sorry`）。

## 2. 打分规则（各 0–5）

- **解释力** — 是否真正压缩/澄清问题（vs. 换名字）。
- **与已知理论的联系** — 与 Elsholtz–Tao / Mordell / Bright–Loughran / 二次互反等的接合度。
- **产生证明的能力** — 能导出多少新定理/判定。
- **可形式化性** — 在*本* Mathlib 构建里变 `sorry`-free 定理的代价。
- **新颖性** — 可引用新陈述的概率。

总分 = 解释力 + 联系 + 产生证明 + 可形式化 + 新颖性。

## 4. Grothendieck 检验的裁定

**通过检验（真正增加结构）**：#1、#2、#5、#6，以及 #3/#4（作为新语言）。
- #2 把「两条同余」坍缩为「一条」，这是**可验证的**结构坍缩，是唯一一件**本阶段从 B 升为 A**
  的事。
- #5 是最深的结构（乘积集刻画），但它等价于猜想本身，诚实标 **C**。

**未通过（换名字 / 已知概念的重发现）**：#8（2-进剖面 = 奇偶定理换说法）、#9、#10（几何/类域
是*已知*的重发现，贡献负结果而非新工具）。

**失败 / 思辨**：#7（证书无可乘结构）、#11（只给密度）、#12（无定义性质）、#13（无定理）。

## 5. 结论

锦标赛的赢家是**单边除子判据 + 除子余数集**这一对：前者是新定理（统一 `a=3/7/…`），后者是
承载它的新对象。二者都不触及六类核心——它们使「容易层」的判定**可验证且统一**，而把真正的
结构猜想（#5，有界指数乘积集）诚实地留给未来。**猜想仍未解决，且不声称已解决。**
