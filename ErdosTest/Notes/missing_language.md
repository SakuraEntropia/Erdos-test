# Phase 9, Step 1 — 缺失的语言：当前方法卡在哪里，缺什么概念

> **Legend:** **A** = proven · **B** = computational · **C** = conjecture · **D** = AI hypothesis.
> This file is the *diagnosis* step of "Mathematical Tool Invention Mode": we do **not** solve the
> conjecture, we ask *which concept is missing* that prevents current methods from progressing.

---

## 1. 一句话诊断

**问题不缺部分结果，缺的是「一个余数集合的对象」**。所有已知方法要么*绕开*六类核心、
要么*无视*它（密度）、要么*解释它为何特殊*而不产出解。缺的是一个把证书条件**压缩成一次
成员测试**、并带有**有界指数乘积集结构**的除子-余数结构。

---

## 2. 为什么现有五种观点都「只差一步」

沿用 `bottleneck_analysis.md` 的五分法，逐一看「这个观点缺什么概念」：

| 观点 | 它已有的 | 它缺的（本阶段要补的） |
|---|---|---|
| **数论（除子参数化）** | 解 ⟺ 证书 `d·e=M²`、`a∣d+M`、`a∣e+M`（`solvable_iff_certificate`）**[A]** | 把「两条同余」**坍缩成一条**（单边判据）；把「目标余数 `−M`」**命名**为一个对象，而不是每次重推 |
| **代数（模/群）** | `gcd(M,a)=1` 时 `d,e ∈ (ℤ/a)^×` | 把 `M²` 的因子模 `a` 取得的余数**当作一个集合** `R(M,a) ⊆ (ℤ/a)^×` 研究，而不是当作散落的除子 |
| **几何（Cayley 三次曲面）** | 无 Brauer–Manin 障碍（负结果）**[A]** | 缺一个「正面的」整数点枚举语言；几何视角给出*障碍*，不给*构造* |
| **概率（随机除子模型）** | 平均有解、密度 1 **[A]** | 缺一个*逐点*（pointwise）判据，概率模型给不出 `∀` |
| **计算（筛/枚举）** | 精确到 `10^18` 的验算 **[B]** | 缺一个*统一*的证书判据，使每个 `a`-层可判定而不必逐类枚举恒等式 |

**结论：** 唯一「增加结构」的方向仍是**除子参数化**（Agent 2 的核心判断，被 1/3/4 号 Agent
确认）。但除子参数化至今缺少一个**语言**：它把解写成了证书，却从未把证书条件本身当对象研究。

---

## 3. 真正缺失的概念（本阶段的候选，Step 3 展开）

1. **除子余数集 `R(M,a) := { d mod a : d ∣ M² }`**（新定义）。证书条件 ⟺ `−M mod a ∈ R(M,a)`。
   这使「`a=3` 可解」等判定从「找一对互补因子」变成「**一次成员测试**」。

2. **单边判据**（新定理）。`gcd(M,a)=1` 时，两条同余 `a∣d+M ∧ a∣e+M` **坍缩**为一条 `a∣d+M`。
   这统一了 `a=3`、`a=7` 与一切素 `a` 层——此前 `a=3` 是手工特殊情形，`a=7` 需要 6 个余数。

3. **`a`-层分解 `AstratumSolvable n a`**（有用的重构）。可解性 = 「存在参数 `a` 的层可解」。
   使「最小证书 `a`」这个此前只在计算里出现的不变量成为正式定义。

4. **有界指数乘积集结构**（新猜想结构，C）。`R(M,a)` 不是一般子群，而是
   `{ ∏ p_i^{f_i} : 0 ≤ f_i ≤ 2 v_i(M) }` 模 `a`（Agent 3 已纠正「子群」这一错误直觉）。
   **这是最值得追的结构事实**：若能刻画 `R(M,a)` 的乘积闭包何时回到 `−M`，就等价于猜想。

---

## 4. 为什么这一步「发明工具」而不是「证明」

Grothendieck 的教训：进展常来自「**换一个正确的对象**」而非「硬证旧对象上的定理」。本阶段
的赌注是：六类核心 `n ≡ 1,121,169,289,361,529 (mod 840)` 之所以顽固，可能是因为**正确的
对象尚未命名**——即「`M²` 的因子余数集 `R(M,a)`」及其乘积集结构。本阶段把可验证的那一部分
（单边判据、a-层、除子余数集的定义）形式化，把不可验证的那一部分（有界指数乘积集的结构
定理）**诚实标为猜想**，绝不在二者之间含糊。
