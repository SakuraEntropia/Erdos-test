## 1. 当前数学瓶颈（一句话 + 指向）

见 `irreducible_core.md`。一句话：**问题等价于「对每个素数 `p ≡ 1,121,169,289,361,529 (mod 840)`，
证明单个 `M = p(p+a)/4` 有一个因子落在剩余类 `−M (mod a)`」** —— 即**「除子在给定剩余类」**，
等价于**「群同态下指数盒（离散对数球）的像是否命中目标」**。这是一个**逐点**存在性，不是密度。

## 2. 四条独立攻击轨道的结果（Part 2）

### Track A — 加性组合（**D：不适用，失败**）

`R(M,a) = { d mod a : d ∣ M² }` 的**来源是乘性的**（除子格），不是加性的（和集）。加性组合的
工具（和集 `A+B`、Cauchy–Davenport、Ruzsa 距离、加法能量）作用于**加法**结构；这里唯一的加法
结构是单个线性同余 `d ≡ −M (mod a)`，**不是**和集现象。没有可用的环境加法。**结论：加性组合
是错误工具**——问题结构是乘性的，难度在「除子/指数盒」，不在「和集」。这是**负结果**，但有用
（排除了一整类方法）。

### Track B — 乘性数论（**正确的框架 + 一条精确恒等式**）

正交性给出**精确**计数公式（标准、**register A（文献）**，本仓库未 Lean 验证）：

> `gcd(M,a)=1` 时，`N(r) = #{ d ∣ M² : d ≡ r (mod a) }` 满足
> `N(r) = (1/φ(a)) Σ_χ χ̄(r) · ∏_{p∣M} ( 1 + χ(p) + χ(p)² + ⋯ + χ(p)^{2 v_p(M)} )`，
> 其中 `χ` 跑遍模 `a` 的 Dirichlet 特征。

这是**完全显式**的：`d ∣ M²` 的因子按指数 `f_p ∈ [0, 2v_p(M)]` 分解，`Σ_{d∣M²} χ(d)` 因式分解为
几何和。要证明 `N(−M) ≥ 1`，只需证这个特征和**非零**。**障碍**：特征和估计给的是**平均/密度**
结果（Fouvry–Klüners 类），**给不出逐点 `N(−M) > 0`**。这正是 Vaughan/Elsholtz–Tao 的同一堵墙。

**诚实判断**：这条轨道把问题**精确地**翻译成一个特征和，但没把墙移走。

### Track C — 代数结构（**正确定位难度，C：等价重构 + 一条新结构定理**）

`φ : ℤ^r → (ℤ/a)^×`（`gcd(M,a)=1`）是群同态，`R(M,a) = φ(Box)`（指数盒的像）。新结构定理
`divisor_of_square_iff_exponent_le`（**Phase 11 [A]**）给出这个「盒」的严格内容：

> `d ∣ M² ⟺ ∀ 素 p, v_p(d) ≤ 2·v_p(M)`。

于是问题 = **离散对数球成员测试**。**不变量**：`φ(Box)` 的大小、`|H| − |φ(Box)|`（盒的「缺陷」），
以及**禁止剩余类** = `H ∖ φ(Box)`。**轨道/陪集结构**：`φ(Box)` 一般不是 `H` 的陪集并（Phase 10
反例）。**结论**：这**正确定位**难度在「盒约束」，但不减少它。**等价难度（C）**。

### Track D — 计算（**B：见 `core_residue_analysis.md`**）

签名（`p ≤ 5·10⁶`）：非难类（61,113 mod 840）minimal `a` **恒为 3**；六难类 median `a=7`、
max 39–59。记录按类分层（class 121、361 增长最快）。工作因子 `d` 很小很光滑。**结论**：困难是
**目标侧**（`a=3` 失效后被迫上升），不是**结构侧**。全部 register B，不外推为定理。

## 3. 较弱的突破（Part 4）—— 诚实区分「做到了」与「没做到」

**做到了（Lean 验证，[A]）：**

- `solvable_of_exists_prime_three_mod_four`：**任何**有素因子 `≡ 3 (mod 4)` 的 `n` 都可解。这
  把硬集从「`n ≡ 1 (mod 4)`」**进一步收紧**为「`n` 的**全部**素因子 `≡ 1 (mod 4)`」。这是本阶段
  最有意义的部分定理。
- `infinitely_many_solvable`：无穷多个可解的 `n`（`n ≡ 3 (mod 4)` 全体）。平凡，但诚实。

**没做到（且诚实说明不声称做到）：**

- 「所有素数」「所有数」—— 这正是猜想本身，**未解决**。
- 「除有限个类之外全成立」—— 即 Vaughan 的密度 1 结果，**已知 [A（文献）]**，但需大筛，
  **本仓库无法形式化**（`known_results.md` §5），且它**不是**「除有限类之外」，只是密度 0 例外。
- 「minimal `a` 无界」—— 只有数据（B），**未证明**（C）。

## 5. 失败的方法（诚实记录，register D）

1. **加性组合**（Track A）：结构是乘性的，无和集可攻。**D**。
2. **特征和直接给逐点**（Track B）：只能给密度/平均，给不出 `N(−M)>0` 的逐点。**D**（作为
   「一步到位的解法」失败；作为「精确重述」仍是 A 级文献恒等式）。
3. **改结构以降难度**（Phase 9/10 遗产）：`divisorResidueSet`、`AstratumSolvable`、有界指数乘积
   集都是**等价重构**，不减少难度；「子群」过度简化已被反驳。**D / C**。
4. **`minimal a` 无界**：数据支持但不可由数据证明。**C**（非失败，是开放猜想）。

## 6. 最有希望的进攻方向

**不是**「再换一个结构」（Phase 9/10 已证等价重构不降难度）。而是：

1. **把「不可约核心」本身做成定理**：形式化 **Mordell 六类约化**（~200 条模恒等式 + CRT，见
   `known_results.md` §4）。这把「只需六个类」从**文献引用**变成 **Lean 定理**，是诚实、可完成、
   且非平凡的下一个里程碑。它不解决猜想，但把「还差什么」钉死在六个类上。
2. **（探索）** 用 Track B 的精确特征和公式，尝试从「`N(−M)` 是**非负整数**」推出对 `(p,a)` 的
   **必要条件**（例如对某特征 `χ` 的几何和 `1+χ(p)+⋯` 的整除/符号约束）。这是 register **C/D**，
   不保证成功。
