# Phase 11, Part 1 — 不可约核心（Irreducible Core）

> **Legend（项目注册表，不变）:** **A** = proven · **B** = computational · **C** = conjecture ·
> **D** = AI hypothesis.
> **Honesty rule（不变）:** 本文件不声称 Erdős–Straus 猜想已解决；它只精确刻画「所有约化之后
> 还剩什么」。

---

## 0. 一句话结论

所有已知约化做完之后，剩下的是一个**单个对象的单个成员测试**：

> 对每个素数 `p ≡ 1 (mod 4)`，构造一个整数 `M = p(p+a)/4`（`a ≡ 3 (mod 4)`，`p+a` 被 4 整除），
> 使得 **`M²` 有一个因子 `d` 落在剩余类 `−M (mod a)`**。

难度不是「找到解」，而是「证明一个**特定的数** `M` 在**特定的模** `a` 下有一个**特定剩余类**
中的因子」。这是数论里著名的**「除子在给定剩余类」**（divisor in a residue class）问题。

---

## 1. 所有约化之后还剩下什么

```
Conjecture  (∀ n ≥ 2, 4/n = 1/x + 1/y + 1/z)
   ↓  [A] reduction_to_primes：伸缩不变性 + 强归纳
   ↓  ⇔ 只需对所有素数 p 成立
   ↓  [A] easy_classes：2∣n ∨ 3∣n ∨ n≡3(mod4) 均已参数化解
   ↓  只需素数 p ≡ 1 (mod 4)
   ↓  [A, published] Mordell 六类约化：模 840 恒等式覆盖其余 834 类
   ↓  只需 p ≡ 1, 121, 169, 289, 361, 529 (mod 840)
```

最后一行的六个类是**不可约核心**。它们等价于（见 `bottleneck_analysis.md`）：

```
p ≡ 1 (mod 24)  且  p 是模 5、模 7 的二次剩余
⇔ p 由 x² + 840 y² 表示
⇔ p = 1², 11², 13², 17², 19², 23² 的模 840 类（的素数）
```

---

## 2. 必须被证明存在的对象

证书双射（`solvable_iff_certificate`，**[A]**）说：`4/n` 可解 ⟺ 存在证书 `(x, a, d, e)`。在
`gcd(M,a)=1`（素 `a` 层自动成立）时，单边判据（`certificate_iff_one_sided`，**[A]**）把它压成
**一个**存在量词：

```
∃ x,  ∃ a = 4x − n > 0,  ∃ d ∣ (n·x)²,   a ∣ d + n·x    (M := n·x)
```

即，令 `M = n·x`，**必须被证明存在的对象**是：

> **一个因子 `d ∣ M²`，满足 `d ≡ −M (mod a)`。**

这就是全部。没有第二层结构。`solvable_of_one_sided_divisor`（**Phase 11 新增 [A]**）把这件事
写成了 `Solvable` 层的充分判据。

---

## 3. 缺失的「覆盖」性质

把 `a` 也当作自由变量，猜想的极小形式是：

> **覆盖陈述（C）**：对每个素数 `p ≡ 1 (mod 4)`，存在 `a ≡ 3 (mod 4)`（`p+a ≡ 0 (mod 4)`），使
> 得目标 `−M mod a ∈ R(M,a)`，其中
>
> `M = p(p+a)/4`，`R(M,a) = { d mod a : d ∣ M² }`（`divisorResidueSet`，Phase 9 [A]）。

缺失的性质是**逐点覆盖**：单个 `M` 必须被它自己的因子余数集 `R(M,a)` **命中目标** `−M`。我们
不需要「几乎所有」，我们需要**每一个**。

- **容易的部分（已知结构）**：`R(M,a)` 的定义、它与证书的双射、单边坍缩、素 `a` 层的 `gcd=1`
  自动性。这些都已 Lean 验证（Phase 9/10/11）。
- **困难的部分（未解决步骤）**：证明目标 `−M` **确实落在** `R(M,a)` 里——对每一个 `p`、某个
  `a`。这不是语言问题，是**存在性**问题。

---

## 4. 是哪个量词制造了困难？

比较三个等价陈述：

| 陈述 | 量词 | 困难 |
|---|---|---|
| 原始 | `∀ n ≥ 2, ∃ x y z > 0, 4/n = …` | `∃ x y z` 在**无限**域上 |
| 证书 | `∀ n, ∃ x a d e, … 整除/同余` | `∃ d` 在 `{d : d ∣ (n·x)²}` 上 |
| 除子余数 | `∀ p ≡ 1(4), ∃ a, −M ∈ R(M,a)` | `∃ d` 在**有限但指数大**的除子集上 |

制造困难的是**第三个量词**：`∃ d ∣ M²`。它不是「在无限集合里找」，而是「在一个**确定的、有限
的、但结构上是组合的**集合 `{d : d ∣ M²}` 里，命中一个同余类」。这个集合的大小 `τ(M²)` 可以
指数大，但**结构完全由 `M` 的素因子决定**——这正是 Phase 11 Track C 要攻击的角度（见 §5）。

## 5. 精确瓶颈 = 「除子在剩余类」，即「指数盒的像是否命中目标」

Track C 的严格形式（`divisor_of_square_iff_exponent_le`，**Phase 11 新增 [A]**）：

```
d ∣ M²  ⟺  ∀ 素 p,  v_p(d) ≤ 2·v_p(M)
```

设 `M = ∏ p_i^{v_i}`。`M²` 的因子全体 = 指数盒 `[0, 2v₁] × ⋯ × [0, 2vᵣ]` 的「多重指标」全体。
当 `gcd(M,a)=1` 时，映射

```
φ : ℤ^r ⟶ (ℤ/a)^× ,   (f₁,…,fᵣ) ↦ ∏ (p_i mod a)^{f_i}
```

是**群同态**，且 `R(M,a) = φ( [0,2v₁] × ⋯ × [0,2vᵣ] )`（**盒的像**）。

于是瓶颈精确为：

> **群同态下，一个「指数盒」（离散对数球）的像是否包含给定目标 `−M`。**

- 若指数**无界**：像就是子群 `⟨p_i⟩ ⊆ (ℤ/a)^×`，成员测试是纯群论（容易，Phase 10 已证）。
- 指数**有界**：像一般是子群的**真子集**（Phase 10 反例 `R(2,5)={1,2,4} ⊊ ⟨2⟩`），成员测试是
  **组合约束**。**难度全部在这里。**

## 6. easy / hard 的分界线（诚实标注）

- **easy（已知结构，register A）**：伸缩 `scale`、素数约化 `reduction_to_primes`、偶/3/`≡3(4)`
  参数化 `easy_classes`、证书双射 `solvable_iff_certificate`、单边判据
  `certificate_iff_one_sided`、指数盒刻画 `divisor_of_square_iff_exponent_le`。
- **hard（未解决步骤，register C）**：`∀ p ≡ 1,121,169,289,361,529 (mod 840)`，目标 `−M` 命中
  `R(M,a)`。这一步**没有**任何已知的、可验证的一般机制。
