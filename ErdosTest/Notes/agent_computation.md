# Agent Computation — New Structure in the Erdős–Straus Divisor Certificate

> **Legend (standing convention):** A = proven · B = computational evidence (finite range) ·
> C = conjecture · D = AI hypothesis. **Everything below is register B unless explicitly marked A-pending.**
> No proof is claimed anywhere in this file.

This session ran NEW experiments on the divisor-certificate bijection
(`solvable_iff_certificate`: a solution with `x = (n+a)/4` exists iff `M = n·x` has complementary
divisors `d·e = M²` with `a ∣ d+M`, `a ∣ e+M`). All arithmetic is exact (Sympy `factorint`,
`Fraction`). Scripts live in `ErdosTest/Experiments/`: `a_prime_subgroup.py`,
`identities_minimal_a.py`, `hard_classes_divisors.py`.

## 1. Experiments run and their exact outputs

### E1 — the certificate reduces to a SINGLE residue condition (one-sided divisor criterion)

**Question.** Does `a ∣ d+M` alone force `a ∣ e+M` when `d·e = M²`? I.e. is
"`a` works ⟺ `M²` has a divisor `d ≡ −M (mod a)`"?

**Method.** Compare the full two-sided certificate `a_works(p,a)` against the one-sided test
"∃ divisor `d | M²` with `(d+M) % a == 0`", for `p ≡ 1 (mod 4)` prime.

**Exact output** (primes `p ≤ 40000`, `q` prime; and `p ≤ 30000`, composite `a`):

| `a` | primes | mismatches |
|---|---:|---:|
| 3, 7, 11, 19, 23, 31, 43 (each, p≤40000) | 2085 each | **0** |
| 15, 21, 27, 35, 39, 45, 55, 63, 91, 119 (each, p≤30000) | 1611 each | **0** |

**Conclusion.** The one-sided criterion matches the full certificate everywhere tested — including
composite `a` where `gcd(M,a) > 1`. For the `gcd(M,a)=1` case this is elementary: `d ≡ −M (mod a)`
forces `gcd(d,a)=1`, so `e = M²/d ≡ M² d⁻¹ ≡ M²(−M)⁻¹ ≡ −M (mod a)`.

> **Corrective note.** A first attempt guessed that the attainable residues of divisors of `M²`
> form the *subgroup* of `(Z/a)^×` generated by the prime factors of `M`. That is **FALSE**: for
> `a=7, p=5`, `M=15`, the residues of divisors of `M²=225` are `{1,2,3,4,5}` (not the full group
> `{1,2,3,4,5,6}`), because the exponents are **bounded** `0..2·e_i`. The correct object is the
> *bounded-exponent* product set `R(M,a) = { ∏ r_i^{f_i} mod a : 0 ≤ f_i ≤ 2 v_i(M) }`. The
> subgroup idea would have been right only if every exponent were large enough (`2e_i ≥ ord(r_i)−1`).

### E2 — target coset law: where does `−M (mod q)` live?

`x = (n+q)/4 ≡ n·4⁻¹ (mod q)` and `M = n·x ≡ n²·4⁻¹ (mod q)`, so

> `−M ≡ −n²·4⁻¹ (mod q)` — a fixed coset `(−4⁻¹)·(squares)`.

**Exact output** (verified on every prime `p≡1 (mod 4)`, `p ≤ 40000`):

- `q = 7`: `−M mod 7` is **always** in `{3,5,6}`.  Correspondence (`t = −M mod 7 = 5p²`):
  `p ≡ 1,6 (mod 7) ⇒ t = 5`;  `p ≡ 2,5 ⇒ t = 6`;  `p ≡ 3,4 ⇒ t = 3`.
- `q = 11`: `−M mod 11` is **always** in `{2,6,7,8,10}` (`= 8p² mod 11`).
- For `q ≡ 3 (mod 4)`, `−1` is a non-residue so `−4⁻¹` is a non-residue ⇒ the coset is exactly the
  **quadratic non-residues** mod `q`. (This is why only `q ≡ 3 (mod 4)` primes can be values of
  `a = 4x − n ≡ 3 (mod 4)`.)

## 2. Conjectures (each with Name / Statement / Evidence / range)

### C1 — One-sided divisor criterion (the certificate is a single residue condition)
- **Statement.** For `n ≡ 1 (mod 4)` and `a ≡ 3 (mod 4)`, `a > 0`, a solution with `x = (n+a)/4`
  exists **iff** `M²` has a divisor `d` with `d ≡ −M (mod a)`, where `M = n(n+a)/4`.
  (The second condition `a ∣ M²/d + M` is then automatic.)
- **Evidence.** 0 mismatches vs the full two-sided certificate for `a ∈ {3,7,11,19,23,31,43}`,
  primes `p ≤ 40000` (2085 each), and composite `a ∈ {15,21,27,35,39,45,55,63,91,119}`, primes
  `p ≤ 30000` (1611 each).
- **Status/range.** Register B. In the `gcd(M,a)=1` case (which includes every prime `a = q`, `q ≠ p`)
  it is elementary — one line from `e ≡ M² d⁻¹`. The general `gcd(M,a) > 1` case is verified
  numerically but the short gcd argument is not yet written down (**A-pending**).

### C2 — Target coset law for prime `a = q`
- **Statement.** For prime `a = q` and `n ≡ 1 (mod 4)`, `n ≠ q`: `−M ≡ −n²·4⁻¹ (mod q)` always lies
  in the coset `(−4⁻¹)·(quadratic residues mod q)`. When `q ≡ 3 (mod 4)` this coset is exactly the
  **non-residues**; concretely `q=7: −M ∈ {3,5,6}`, `q=11: −M ∈ {2,6,7,8,10}`.
- **Evidence.** Matches for every prime `p ≡ 1 (mod 4)`, `p ≤ 40000`; the `{3,5,6}` / `{2,6,7,8,10}`
  sets are saturated (every element attained).
- **Status/range.** Register B; the algebra (`M ≡ n²/4`) is elementary (**A-pending**).

### C3 — Two new parametric identities (infinite explicit solution families)
- **Statement.** For every prime `q ≡ 3 (mod 4)` and every `n ≡ 1 (mod 4)`:
  - (i) `n ≡ −4 (mod q)`:  `4/n = 1/x + 1/y + 1/z` with
    `x = (n+q)/4`, `y = n(n+q+4)/(4q)`, `z = n(n+q)(n+q+4)/(16q)`  (here `a = q`, `d = n`).
  - (ii) `n ≡ −1 (mod q)`:  `4/n = 1/x + 1/y + 1/z` with
    `x = (n+q)/4`, `y = (n+q)(n+1)/(4q)`, `z = n(n+q)(n+1)/(4q)`  (here `a = q`, `d = x`).
- **Evidence.** `0` failures over primes `p≡1 (mod 4) ≤ 10^5` for `q ∈ {3,7,11,19,23,31}`, and
  `0` failures over **all** `n ≡ 1 (mod 4) ≤ 50000` (composite included) for `q ∈ {3,7,11,19}`.
- **Status/range.** Register B; these are closed-form and provable by `ring` (no factorization) —
  the **easiest to formalize**. For `q = 3` both reduce to `n ≡ 2 (mod 3)` (the known `a=3` easy case).

### C4 — Complete characterization of `a = 7`
- **Statement.** For `n ≡ 1 (mod 4)`, `n ≠ 7`, let `x = (n+7)/4` and `D(x²)` be the set of residues
  mod 7 attained by divisors of `x²` (exponents `0..2e_i`). Then
  `a = 7` works ⟺ `D(x²) ∩ {5n², 5n, 5} ≠ ∅ (mod 7)`.
  In particular `a = 7` works for **all** `n ≡ 3` or `6 (mod 7)` (via `d = n` resp. `d = x`).
- **Evidence.** 0 mismatches vs the full certificate over 4783 primes `p ≤ 10^5`; success rates by
  `p mod 7`: 61% / 73% / **100%** / 73% / 80% / **100%** for `p ≡ 1,2,3,4,5,6`.
- **Status/range.** Register B. The two 100% classes are exactly C3(i)/(ii) at `q=7`; the remaining
  classes need the divisor-residue enumeration (**A-pending**, needs factorization machinery).

### C5 — Minimal `a` forms a complete initial segment (every `a ≡ 3 (mod 4)` occurs)
- **Statement.** For primes `p ≡ 1 (mod 4)`, `p ≤ 2·10^6`, the set of minimal `a = 4·x_min − p` is
  exactly `{3,7,11,15,19,23,27,31,35,39,43,47,51,55,59}` — every residue `≡ 3 (mod 4)` up to 59 is
  attained, none skipped — and the maximum is 59 (first at `p = 118801`). Conjecturally **every
  `a ≡ 3 (mod 4)` occurs as a minimal `a` for some prime**, and minimal `a` grows very slowly.
- **Evidence.** 74416 primes `≤ 2·10^6`, full search `a ≤ 599`; first-occurrence table in §E5.
- **Status/range.** Register B (finite range); the "every `a` occurs" tail is **C/D** (not provable
  from this data). Not a bound on minimal `a` — just evidence it is small in practice.

## 3. Which conjectures look most promising to formalize (Lean)

1. **C3 (the two identities) — highest ROI.** Pure `ring`/`omega` algebra, no factorization, exact
   closed forms. Directly extends the existing `ACases.lean` (`five_mod_eight_minimal`) style.
   Recommended first target.
2. **C1 (one-sided criterion), `gcd(M,a)=1` case.** Needs: `d | M²`, `d ≡ −M (mod a)`,
   `gcd(M,a)=1 ⟹ gcd(d,a)=1`, and `ZMod` invertibility to conclude `e ≡ M² d⁻¹ ≡ −M`. This is a
   clean, short lemma that turns the 2-condition certificate into a 1-condition one. The prime-`a`
   slice (`a = q`) is the natural Lean statement.
3. **C2 (coset law).** Needs only `M ≡ n²/4 (mod q)` and the fact that `−1` is a non-residue mod a
   prime `q ≡ 3 (mod 4)` (Euler's criterion in `ZMod`). Short but touches quadratic residues.
4. **C4.** The two 100% classes reduce to C3; the full `a=7` iff needs divisor/factorization
   machinery (`Nat.factors`, divisor enumeration) — heavier, defer.
5. **C5.** Empirical; not a Lean target (existence over all primes is exactly the hard part).

**Bottom line.** Nothing here crosses the six-class core; the certificate bijection remains
*equivalent* to the conjecture. The genuinely new, concrete, and likely-formalizable content is
(C1) the collapse of the certificate to one residue condition, and (C3) the two new parametric
families `n ≡ −4, −1 (mod q)`.
