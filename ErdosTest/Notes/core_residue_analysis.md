## 0. 六个类是什么

```
n ≡ 1, 121, 169, 289, 361, 529 (mod 840)   =   1², 11², 13², 17², 19², 23² (mod 840)
```

它们**恰是** `≡ 1 (mod 4)` 中、且 `≡ 1 (mod 3)`、且模 5、模 7 都是二次剩余的类，等价地：

```
p ≡ 1 (mod 24)  且  (p/5) = (p/7) = +1   ⟺   p 由 x² + 840 y² 表示
```

（二次剩余刻画是「为什么难」的**数论**答案：这些类躲开了每一个模恒等式，因为它们正是
`x²+840y²` 的素数，落在某个**亏格**里。）

## 1. 为什么容易的构造失败

所有「容易」的类都由**多项式参数化恒等式**覆盖，且**多数**由 `a = 3` 层（最小证书层）覆盖。
计算（register B）显示了一个干净的签名：

| 类 (mod 840) | 性质 | minimal `a` 的分布（`p ≤ 5·10⁶`） |
|---|---|---|
| 61, 113 | **非难类**（示例） | **恒为 3**（mean 3.0, max 3） |
| 1, 121, 169, 289, 361, 529 | **难类** | median 7, mean 7.7–8.5, max 39–59 |

即：**非难类里 `a=3` 层永远够用；难类里 `a=3` 层对某些素数失效**，被迫用到更大的 `a` 层。

`a=3` 层何时失效是**已知定理**（`A3Characterization`，[A]）：

```
a = 3 可解  ⟺  p ≡ 2 (mod 3)  或  (p+3)/4 有素因子 ≡ 2 (mod 3)
```

而六类核心都满足 `p ≡ 1 (mod 3)`，所以 `a=3` 可解**当且仅当** `(p+3)/4` 有素因子 `≡ 2 (mod 3)`。
当 `(p+3)/4` 只有 `≡ 1 (mod 3)` 的素因子时，`a=3` 层直接失败——必须上升到 `a=7, 11, …`。
这就是「容易构造失败」的**精确机制**。

## 3. 从表里能诚实读出的东西（register B，不可外推为定理）

1. **工作因子 `d` 很小、很「光滑」**：几乎总是 `d ≪ p`，且 `d` 的素因子是小素数（2,3,5,7,13,
   17,19,29,…）。这与「证书除子 `d ∣ M²` 通常可取得很小」一致——**困难不在于 `d` 大，而在于**
   `d` **必须同时满足同余** `d ≡ −M (mod a)`。

2. **`d` 的分解与 `a` 关系松散**：看不出 `d` 必须是 `a` 的函数。有些 `d = 11, 13, 17`（小素数）
   反复出现，说明同一小素因子在不同 `p` 上反复充当工作因子。

3. **minimal `a` 的增长按类分层**：class 121、361 增长最快（记录到 59），class 1 次之（47），
   class 289 最慢（39）。这是「六类内部还有再分层」的**计算签名**，但没有证明任何类的
   minimal `a` 无界（那是 **C**，数据只到 5·10⁶）。

4. **`a=3` 频繁成功**：即使是最难的类，仍有很多素数 `a=3` 就够（表中大量 `a=3`）。这与
   `A3Characterization` 的判据一致：`(p+3)/4` 有 `≡2 (mod 3)` 素因子时 `a=3` 即解。

## 4. 剩余类约束的精确形式

六类核心的**定义性约束**（为什么被剩下）：

```
p ≡ 1 (mod 4)      —— 否则参数化恒等式已覆盖
p ≡ 1 (mod 3)      —— 否则 a=3 层已覆盖
p ≡ 1 (mod 8)      —— 否则仿射 (x,y) 恒等式已覆盖（Phase 4 观察到 n≡1(8) 的障碍）
p ∈ {±1, ±(±29)?} (mod 5), (mod 7) 的二次剩余类 —— Mordell 恒等式覆盖其余
```

在「指数盒」语言（`irreducible_core.md` §5）里，这些约束**不改变** `R(M,a)` 的**结构**（它始终
是盒的像），它们只**限制**目标 `−M mod a` 落在哪些 `(p, a)` 上。所以六类核心是**目标侧**的难，
不是**结构侧**的难——这解释了为什么所有「改结构」的尝试（Phase 9/10）都不降低难度。

## 5. 结论（诚实）

六类核心的困难可以**精确定位**为：`a=3` 层的失效（机制已知，`A3Characterization`）+ 更高 `a`
层「目标 `−M` 命中指数盒像」的**逐点**存在性（机制未知）。本文件把这两层分开：前者是已证
结构，后者是 register **C** 的开放步骤。**不声称解决。**
